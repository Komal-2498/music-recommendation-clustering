# 🎶 Music Recommendation System using Clustering

This project groups songs into **clusters** based on their musical attributes to help build **playlist recommendations**.  
It uses **unsupervised learning (K-Means)** to discover patterns in audio features such as tempo, energy, loudness, valence, etc.

---

## 📌 Project Overview

Music streaming platforms like Spotify and YouTube Music recommend songs that match a listener’s mood and preferences.

To simulate this behavior, this project:

1. Loads and cleans a dataset of songs with musical attributes  
2. Scales features to ensure balanced cluster formation  
3. Uses **K-Means clustering** to group similar songs  
4. Evaluates and visualizes clusters  
5. Shows how a **recommendation lookup** can be made based on cluster similarity
